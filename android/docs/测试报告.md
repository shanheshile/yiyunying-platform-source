## 测试边界

1. 本地全新数据库安装已验证 L1/L2/L3/L4 四个身份均能登录；生产服务器应先部署本次 `yiyunying-backend` 并执行升级 SQL，再做生产数据下的只读验收。
2. 本轮构建时 `adb devices -l` 没有连接实体设备或可用模拟器，因此完成了 JVM、Lint、Dex、签名和 APK 打包验证，未把真机手势、输入法和通知栏展示宣称为已自动化通过。
3. Debug APK 使用 Android 调试证书，只适合测试。商店发布、升级兼容和证书保管必须使用项目方自己的长期 release keystore。
4. 当前服务器使用 HTTP。功能上可对接，但账号与 Token 可能被同网段窃听；生产验收必须迁移 HTTPS。

## Android 16 专项修复

- 小米 Android 16 真机诊断确认旧表达式 `\\{([a-zA-Z0-9_]+)}` 会被 Android ICU 拒绝。
- 当前表达式已修正为 `\\{([a-zA-Z0-9_]+)\\}`。
- 页面与接口保护同时增加 `LinkageError` 处理，类静态初始化兼容错误不再直接终止整个 App。

## 本轮可视化与社交闭环

- 四端统一为白色主背景、蓝色强调色、紧凑 Material 3 控件和状态栏安全区；角色首页、管理下钻和返回栈同步重构。
- 用户端底部为“消息、动态、活动、我的”；动态与活动先展示一级入口，再进入对应二级列表，避免把所有模块堆到侧栏。
- 聊天消息长按操作使用小型毛玻璃面板；会话支持置顶、普通、置底三段及折叠，消息页只展示聊天、客服和机器人。
- 多图/视频消息支持层叠深度、左右滑动切换当前媒体、点击当前项预览和展开/收起动效。
- 视频支持小窗、全屏、倍速、亮度、音量、双击暂停、长按临时加速与下载确认。
- 聊天输入区提供按住说话、滑动取消、语音转文字、最近照片建议，以及两行四列的“相册、拍摄、文件、收藏、红包、转账、名片、礼物”功能面板。
- 相册仅在用户点击后异步加载，支持图片/视频缩略图、完整预览后勾选、原图/原视频模式、超限媒体禁选和批量发送；系统文件选择器负责普通文件。
- 私聊、群聊、客服和论坛支持混合媒体；多图默认叠放显示，可手动展开或收起。
- 转发快照支持嵌套快照递归展示、原身份转发、选择性匿名和全匿名；全匿名为每位原发言人生成稳定的“默认用户 N”别名并清除真实 ID、昵称和头像。
- 论坛按“板块 → 帖子列表 → 帖子详情 → 作者主页”逐级进入，Android 返回栈逐级返回。
- 隐藏详细资料的用户仍展示公开基础主页，QQ、签名、会员等受保护字段不会返回给普通用户。
- 投票分类、多个活动、多个动态选项、单选/多选和投票结果均使用可视化控件。
- 平台和管理员可从应用进入用户列表、中文资料分区及通信审计，不要求手写 JSON。
- 论坛新增免费/付费内容节混排、余额事务购买、服务端遮蔽、节排序、唯一浏览、热度标签、评论/回复互动、作者评论置顶和个人板块/帖子置顶或置底。
- 语音消息在原聊天页内播放，支持进度拖动和 `1/1.5/2/3` 倍速；权限校验后的转写结果位于语音条下方，可展开或收起，编辑框语音输入支持停止与系统识别兜底。
- 群文件和群相册支持批量选择，相册可混合图片/视频；群投票支持多选，群接龙使用服务端连续序号，全部操作保留在群上下文中。
- GIF 与手机动态照片分开识别和显示；图片堆叠左侧显示“展开 N”和当前位置，展开/收起不会留下空白占位。

## 推荐的上线验收

1. 部署 `yiyunying-backend`，导入 `database/install.sql`，确认 `/api/health` 返回成功。
2. 用 `root/authorized/admin/user` 四个测试身份分别登录，确认租户头与数据隔离。
3. 创建第二个平台、第二个管理员和两个应用，验证任何跨平台/跨应用 ID 都返回 403/404。
4. 完成用户注册、笔记 CRUD、固定分享码生成/查询/停用/原码重启用/密码读取、卡密兑换、余额账本、公告版本与统计日志闭环。
5. 开两台设备验证私聊、聊天室、客服会话、强制轮询间隔与后台停止轮询。
6. 切换封禁、会员过期和平台强制开关，确认下级 admin/user 立即无法继续业务操作。
7. 使用正式 HTTPS 域名构建 release 包，完成安装、升级、弱网、断网、Token 过期和进程重启测试。
