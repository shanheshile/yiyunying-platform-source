# 2.7.1 更新说明

版本号：2.7.1（46）

## 本轮修复

- 重构共享弹窗与底部弹层的外观应用流程，避免同一弹层重复换肤造成首帧闪烁。
- 修复自定义背景后的 `MaterialButton` 再设置形状时触发的崩溃。
- 主操作按钮改用稳定的显式圆角背景，避免底部安全区或系统轮廓把按钮底边裁成直角。
- 为生活动态的置顶、删除、恢复、点赞与收藏操作补充页面生命周期保护，避免页面退出后异步回调继续操作界面。
- 私聊首次进入时优先解析本地会话缓存，再刷新网络数据；弱网或离线时可以直接显示已缓存的会话和聊天记录。
