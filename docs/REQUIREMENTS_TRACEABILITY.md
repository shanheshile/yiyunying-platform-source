# 需求追踪

本文件把长期需求按可核验能力归类。状态含义：

- **已实现**：源码中存在完整入口和主要链路，并纳入自动构建。
- **需配置**：实现依赖部署环境提供服务、密钥或系统权限。
- **需真机验收**：自动构建通过，但行为受厂商系统影响。
- **持续完善**：业务面已建立，仍应按具体版本补充体验和边界测试。

| 能力 | 状态 | 核验重点 |
| --- | --- | --- |
| 四角色 Android 与分级权限 | 已实现 | 后端权限复核、审计身份、角色显示 |
| 私聊/群聊/聊天室/客服会话 | 已实现 | 列表、记录、搜索、离线只读、草稿和隐藏会话 |
| 图片/视频/语音/文件/收藏/名片 | 已实现 | 预览、类型化操作、缓存、复制不泄露 URL |
| 多图相册、堆叠、选择与滑动 | 持续完善 | 大相册分页、滚动锚点、方向手势和内存 |
| 消息多选、锚点、嵌套转发和匿名 | 已实现 | 快照只读、匿名层级、管理员审计 |
| 群文件/相册/投票/接龙/公告 | 已实现 | 上传者权限、列表详情、评论、系统消息 |
| 语音/视频通话 | 需配置、需真机验收 | TURN、推送、锁屏、悬浮窗、双向音视频、挂断销毁 |
| 通知中心与聊天通知分离 | 已实现 | 动态/活动/系统分类、红点和一键已读 |
| 动态/笔记与隐私范围 | 已实现 | 时间范围、指定对象、置顶、编辑和详情互动 |
| 论坛/帖子/评论/付费章节 | 已实现 | 板块二级分类、审核、版主、媒体评论和热度 |
| 悬赏/投票活动/举报审核 | 已实现 | 分类、附件、截止时间、审核原因和权限 |
| 资源大厅/应用商店/源码商城 | 持续完善 | 包信息识别、投稿审核、恶意扫描和分类规范化 |
| 商店/余额商店/订单 | 已实现 | 库存、余额、收货信息、评论、追踪和流水 |
| 红包/转账/礼物 | 已实现 | 指定范围、自领规则、随机/按份、退回和运气王 |
| 等级/经验/签到/奖励/抽奖 | 已实现 | 次数规则、奖励类型、概率、库存和记录 |
| 二维码/好友码/相册识别 | 已实现 | 竖屏扫码、退出、加好友/群与相册解码 |
| 全局主题/颜色/语言/图标/背景 | 持续完善 | 所有 Activity 即时刷新、数据名不翻译、别名存在性 |
| AI 问答/天气/新闻/知识 | 需配置 | 地名解析、小时降水、在线模型、来源与降级策略 |
| 语音转文字 | 需配置 | 本地模型、中文/英文/混合识别、收起与离线降级 |

历史需求体量很大，发布时应基于本表选择版本范围并保留真机验收证据。不能用“构建成功”替代通话、推送、支付和厂商权限的实际验证。
