## 本轮实现概览

### 管理审核与权限闭环

- 管理端增加真正落到后端路由、权限服务、审核状态和审计记录的内容审核能力，覆盖动态、帖子和评论等内容类型。
- 管理员开关继续由服务端复核，避免只隐藏客户端入口；新增设置描述、模块注册、统计和审核文档/合同验证。
- 二维码分享等管理端与用户端共用弹层修正主题字体颜色；固定标题区与滚动内容区隔离，避免穿透或重叠。

### 聊天、昵称与撤回

- 聊天展示名不再偶发退化为 `user`；按备注、昵称、账号的明确优先级生成稳定显示名。
- 撤回消息同样优先显示备注，无备注显示昵称，无昵称再显示账号。
- 删除、收藏、转发、点赞、评论、回复等常用动作统一采用图标资源，并保留可访问性标签与点击区域。

### 相机、媒体堆叠与 GIF

- 软件内相机增加可见焦点框；点按聚焦、拖动焦点、长按锁焦，移动和状态反馈由独立控制器约束。
- 图片与视频分别堆叠显示；上层/下层切换动画与错层边界同步，聊天和评论/帖子场景复用同一过渡规则。
- 动图可查看，并提供重复播放、循环观看控制。

### 评论 UI

- 修复动态评论顶部未对齐、圆角区域漏出其他评论以及弹层标题/内容重叠。
- 调整 2.7.13 评论区的内嵌回复、操作区和媒体展示，保持根评论与子回复的视觉归属。
- 音频评论延续可拖动进度、错误恢复与资源释放保护。

### 可恢复下载、安装包历史与更新安全

- 安装包下载支持 HTTP Range/If-Range 续传；严格校验 `206 Content-Range`，服务端返回 `200` 时安全重建，`416` 只在本地完整且符合预期时进入校验。
- 下载中的临时文件、ETag、Last-Modified、进度和状态持久化；异常退出后可继续，多个页面进入同一任务时不会重复下载。
- 设置新增历史安装包入口，可继续下载/安装、单个或批量删除；正在下载的包先暂停再确认删除。
- 增加“安装完成后自动删除”选项，默认关闭；只有确认安装完成才清理，安装失败或授权中断不误删可恢复包。
- 未知来源安装授权返回后继续安装；安装请求、安装完成和替换安装采用持久状态恢复。
- 包名、版本、大小、SHA-256 和签名链全部校验；HTTPS 不允许降级到 HTTP，Release 构建禁止 HTTP，Debug 仅为兼容当前测试链路保留受控 HTTP。
- 更新接口元数据缺少包名、大小或 SHA-256 时失败关闭，避免下载无法可靠验证的安装包。
