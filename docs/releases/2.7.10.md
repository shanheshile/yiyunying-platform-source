# 2.7.10 发布说明

发布日期：2026-08-02

版本：`2.7.10`（Android `versionCode 55`）

本页只声明能够由当前源码、自动化测试与四端构建制品复现的结果。真机视觉、生产签名和生产环境业务联调继续遵循全量完成定义。

## 置顶动态显示修复

- 修复个人动态空间中置顶内容前出现整屏空白、正文被挤出屏幕的问题。根因是时间轴条目采用横向根布局时，置顶区分隔线使用 `match_parent` 宽度并参与同一行测量，吞掉了动态卡片的可用宽度。
- 时间轴条目改为纵向结构：日期与动态卡片保留在同一横向内容行，置顶/普通分区线独立放在内容行下方，不再与正文争抢宽度。
- 分区线只在“当前项为置顶且下一项为普通动态”时显示；全部内容均置顶、列表末项或公共动态均不产生多余空白分隔项。
- 自己进入个人动态空间时继续使用 `mine=1` 查询，置顶动态遵循作者可见规则并稳定进入顶部区域。
- 动态列表关闭固定尺寸假设，嵌套媒体网格在复用前清空，避免九格媒体高度变化后沿用旧测量结果。

## 论坛评论预览与展开

- 主评论下的副评论默认收起，只显示最多两条紧凑摘要；摘要保留回复人、回复对象以及图片、视频、语音、音频、文档或文件类型。
- 展开入口显示真实回复总数并使用 44dp 触控区域和方向图标；可原位展开、收起，点击摘要可展开并定位对应回复。
- 回复继续按稳定根评论与直接父评论归组，新主评论不会导致历史回复串楼或移动。

## 动态可见人员选择

- “仅指定用户”和“除指定用户外”改为好友列表多选器，不再要求手工填写用户编号。
- 选择器支持好友分组、搜索、已选人数和名称回显；保存时仅提交可见范围字段，不改动动态正文。

## 已下载更新包直接安装

- 安装前在后台校验本地 APK 的包名、版本号、大小和 SHA-256。
- 本地存在与服务端目标完全一致的有效安装包时直接调起安装，不再重复下载。
- 过期、损坏或身份不一致的缓存包会被清理，再按原下载流程获取正确版本。

## 自动化验证

- `MomentDisplayPolicyTest`、`ForumCommentThreadOrderTest`、`ForumCommentPreviewPolicyTest` 和 `UpdatePackagePolicyTest` 通过。
- 动态置顶隐私 PHP 契约测试与时间轴 XML 解析通过。
- 四角色 Android 单元测试、Lint、Java 编译和 APK 构建通过，共执行 226 项 Gradle 任务。
- 四个 APK 的包名、包内 `versionName`/`versionCode`、签名存在性、体积与 SHA-256 已通过发布脚本核验。

## 发布边界

- 当前 APK 仍为 debug 验证签名包；正式公开发布仍需受保护且连续的生产签名与覆盖安装验证。
- 当前环境未连接 ADB 设备，置顶动态、九格媒体、评论展开与动态高度变化仍需在小米和 vivo 目标真机完成截图与交互验收。
- 通话生产联调、资金双重记账、恶意文件隔离、实时 AI 检索、三家原生地图和完整四级 RBAC/ABAC 不因本次专项修复而自动完成。
- 全部历史需求、补充需求、实施优先级与完成定义见[全量需求与实施总纲](../MASTER_REQUIREMENTS_AND_IMPLEMENTATION_PLAN.md)。
