# 2.7.9 发布说明

发布日期：2026-08-02

版本：`2.7.9`（Android `versionCode 54`）

本页只声明能够由当前源码、自动化测试与四端构建制品复现的结果。九大产品领域和十一领域总纲仍按逐项完成定义验收，不因本次专项修复而整体标记为生产完成。

## 动态操作与可见范围

- 动态操作拆分为编辑内容、编辑可见范围、置顶/取消置顶、隐藏和删除，不再只剩一个模糊操作入口。
- 内容编辑继续受发布后两分钟限制；超过时间后不能改正文或媒体，但作者仍可长期修改可见人员、可见天数并删除自己的动态。
- “仅指定用户”和“除指定用户外”接入好友列表多选器，保存时仅更新权限字段，不修改正文，也不伪造正文编辑时间。
- 服务端独立提供 `PUT /api/user/moments/{moment_id}/visibility`，并继续在服务端复核作者身份和人员列表。

## 置顶动态可见性

- 置顶动态在对应用户的个人动态空间及详情页允许绕过全局可见天数限制，并在个人空间顶部排序。
- 置顶不会突破“仅自己、仅好友、仅指定、排除指定”、黑名单或关系权限；无权用户仍不可见。
- 公共动态保持普通时间线，不展示普通用户的置顶标识或个人空间置顶分区。

## 论坛评论默认折叠

- 主评论下的副评论默认收起，仅显示最多两条紧凑预览和回复对象。
- 点击“展开 N 条回复”后在当前主评论下展开，再次点击可收起；焦点跳转到某条回复时自动展开所属主评论。
- 回复继续使用稳定根评论锚点归组，新增主评论不会导致已有回复串楼。

## 原图与动图预览

- 图片预览工具栏增加“查看原图”；加载后明确显示“已是原图”。
- GIF/动画图片增加“播放动图”与“重新播放动图”，直接使用原始媒体源，不把动画降为静态缩略图。
- 下载图片或视频时优先保存原始文件；后端媒体接口补齐原图、缩略图、动画标识、原始大小和优化状态。

## 自动化验证

- PHP 语法、环境配置、动态置顶隐私契约和论坛评论契约测试通过。
- `MomentDisplayPolicyTest`、`ForumCommentThreadOrderTest` 以及四角色 Android 单元测试通过。
- 四端 Lint、Java 编译和 APK 构建通过，共执行 226 项 Gradle 任务。
- 四个 APK 的包名、包内 `versionName`/`versionCode`、签名存在性、体积与 SHA-256 已通过发布脚本核验。

## 发布边界

- 当前 APK 仍是 debug 验证签名包，不能冒充固定生产签名的正式商用包；生产密钥托管与覆盖安装验证仍是阻塞项。
- 小米/vivo 的动态菜单、评论折叠、超长昵称、大字体、弱网原图/GIF 与内存压力仍需目标真机交互验收。
- 通话生产联调、资金双重记账、恶意文件隔离、实时 AI 检索、三家原生地图和完整四级 RBAC/ABAC 不因本版专项修复而自动完成。
- 全部历史需求、补充需求、实施优先级与完成定义见[全量需求与实施总纲](../MASTER_REQUIREMENTS_AND_IMPLEMENTATION_PLAN.md)。
