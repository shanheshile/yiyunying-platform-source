# 2.7.4 发布说明与十一领域验收矩阵

发布日期：2026-08-01

版本：`2.7.4`（Android `versionCode 49`）

本页只记录能够由当前源码、数据库迁移、自动化检查或构建产物复核的事实。需求进入矩阵不代表已经交付；涉及资金、通话、推送、地图、模型和四级权限的能力，必须经过服务端联调、并发测试、安全评审或真机验收后才能改为“完成”。

## 本版可核验完成

### 自动缓存与离线管理基础

- 新增账号隔离的自动缓存策略和本地索引，支持图片、视频、语音、音频、文档、普通文件和聊天记录分类。
- 默认开启自动缓存，可分别设置 Wi-Fi、移动网络或从不缓存，支持容量上限、保留天数、自动清理和手动保护。
- 缓存管理页支持搜索、来源、类别、时间筛选、多选、全选当前筛选结果、保护和删除。
- 视频自动播放与自动缓存分别配置网络环境；服务端可下发平台上限，客户端仍保留用户在上限内的选择。
- 自动清理不会删除用户手动下载或明确标记为保留的内容。

### 图片、GIF、动态照片与相册预览

- 图片预览使用缩略图快速首屏，并提供“查看原图”；原图加载失败保留当前可见内容并给出可理解提示。
- GIF 使用原始媒体源加载，保持动图播放，不再被静态缩略图替代。
- 动态照片与 GIF 分开建模；存在配对视频时按动态照片播放，不存在时回退到原始图片。
- 聊天图片组继续使用同类媒体导航，表情包不混入普通图片组，避免表情包预览串到相册图片。
- 媒体元信息可显示类型、文件名、大小、当前序号和总数。

### 视频、语音、音频、文档与普通文件

- 视频预览增加封面、缓冲状态、播放/暂停、进度、时长、倍速和全屏控制，并接入自动播放网络策略。
- 语音与普通音频保持不同语义；音频使用独立播放卡，文档和普通文件使用类型化卡片。
- 文件按 APK/HAP/IPA、PDF、Word、Excel、PPT、压缩包、源码、音频、视频和普通文件显示中文类型。
- 论坛内容、付费章节、评论、收藏快照和共享文档复用统一媒体渲染器，减少同一媒体在不同入口显示不一致。
- 文件详情优先在软件内预览；不支持的格式显示名称、类型、大小和明确操作，不展示原始 JSON。

### 服务端策略与数据库迁移

- 新增自动缓存、视频自动播放、网络策略、容量和保留期限配置项。
- 管理端可设置平台上限与默认值，用户设置只能在服务端允许范围内生效。
- 新增有版本的数据库迁移和缓存/媒体策略烟雾测试脚本。

## 十一领域验收目标

### 1. 消息可靠性与离线浏览

- 使用服务端递增游标、WebSocket 主通道和增量 HTTP 降级，消息具有稳定 ID、幂等键和明确发送状态。
- 用户查看历史时保持滚动锚点；新消息只更新数据并显示“新消息（N）”，由用户主动回到底部。
- 断网可读取已缓存会话、资料、媒体和嵌套转发快照，联网后只补齐缺失增量。
- 验收：弱网无重复消息，历史位置不跳，恢复联网后顺序一致，消息确认 P95 不高于 800 ms。

### 2. 通话、通知与后台运行

- 服务端呼叫状态机带事件序号，统一拨号、响铃、接听、占线、挂断、超时和失败清理。
- TURN/STUN 可健康检查和区域选择，弱网动态降低清晰度而不是直接失去声音或画面。
- 单一高优先级来电通知支持接听/挂断；悬浮窗与主页面共享同一计时源，结束后三秒清理。
- 验收：建立呼叫 P95 不高于 5 秒，双方最终状态一致，小窗计时不中断，多品牌前后台/锁屏通过。

### 3. 媒体、文件、语音与收藏

- 媒体模型严格区分图片、GIF、动态照片、视频、语音、音频、文档、安装包、源码和普通文件。
- 上传采用分片与断点续传，服务端统一生成缩略图、视频封面和可校验的原始文件元数据。
- 收藏按来源渲染快照详情，并提供“看快照”和“回到原位置”两条路径；内部复制不暴露服务器 URL。
- 验收：多媒体上传成功率不低于 99%，无 413 HTML 泄漏，原图/GIF/视频/音频/文件均有类型化 UI。

### 4. 资料卡、权限与隐私

- 用户、群聊、聊天室采用不同资料卡；标题左侧进入资料，右侧进入权限管理，返回栈不得形成资料/权限循环。
- 勿扰、特别关心、黑名单、添加方式、陌生人消息、动态可见范围和群权限均由服务端最终裁决。
- “仅指定用户/除指定用户外”使用好友分组与多选列表，搜索仅用于辅助定位。
- 验收：入口对象正确、返回无环、无网只读不误提交、用户名和用户内容永不被翻译。

### 5. 动态、论坛、悬赏与投票

- 动态支持九格媒体、地点、可见范围、个人空间置顶、一次限时编辑、删除、详情和评论互动。
- 论坛支持板块/二级分类申请、标签词典、版主、审核、付费章节、富媒体评论和热度排序。
- 悬赏支持分类、附件、奖励类型和最长一个月日期选择；投票统一单选/多选、图片选项和结果策略。
- 验收：CRUD、审核、举报闭环，多选投票并发正确，空评论不产生虚假热度标签。

### 6. 资源、商店、余额商店与投稿安全

- APK/IPA/HAP 提取图标、包名、版本、大小和权限；源码识别语言、框架与平台，结果允许人工修正。
- 上传先进入隔离区，经过哈希、签名、恶意样本、压缩包递归和依赖风险检查后才允许审核发布。
- 应用商店、源码商城、普通商店和余额商店保持独立分类、库存、购买资料、评论和订单状态。
- 验收：危险投稿不能公开，分类唯一，审核/封禁可追踪，库存和订单并发一致。

### 7. 红包、转账、礼物、订单与奖励

- 使用以分为单位的不可变双重记账，领取、退回、过期和退款均有事务与幂等键。
- 红包支持按份、随机抢、指定范围、自己领取和运气王；私发只允许接收者退回发送者。
- 奖励规则支持一次、每日次数、奖励种类和额度，订单覆盖商品、资源、付费帖子、会员与权益。
- 验收：并发资金守恒、重复请求不重复扣款、24 小时任务可重放、资金/订单/审计可对账。

### 8. 全局主题、语言、图标、背景与布局

- 单一外观状态源负责主题、颜色、字体、语言、桌面/通知图标和默认/全局/单聊背景。
- 桌面图标只切换真实存在的 Manifest 别名，失败自动回滚；固定文案进入资源系统，用户内容不翻译。
- 验收：四端关键页面三语言、两主题、刘海/手势导航/大字体截图通过，无卡字、错位、留白或组件不存在崩溃。

### 9. 智能机器人、天气、新闻与语音识别

- 问答分为意图识别、实体消歧、工具调用、知识检索、生成和来源标注。
- 行政区划和地理编码解析任意城市/区县；明确地点时不强制定位，天气提供逐小时降水区间和更新时间。
- 本地模型处理隐私敏感与离线基础问答，服务器模型处理复杂检索；全部链路有超时、熔断和降级。
- 验收：固定评测覆盖城市消歧、多学科、实时新闻、中英混合语音、无网和失败降级。

### 10. 四级管理端与平台治理

- 权限采用 RBAC 与对象/租户属性联合校验，前端显隐和后端授权来自同一策略源。
- 1/2/3 按应用进入用户、内容、聊天、论坛、资源、商店、资金、文件、通知、更新和维护系统。
- 管理员代入查看和系统发言保留上下文标识，所有变更记录操作者、原因、前后值、时间、设备与业务对象。
- 验收：越权测试通过，批量管理可撤销或冲正，匿名审计可追溯但不越权扩散，界面无裸 JSON。

### 11. 定位、地图与二维码

- 统一地点对象保存坐标系、名称、地址、精度和时间，正确转换高德、百度、腾讯等坐标体系。
- 软件内地图展示自己/对方标记、距离和隐私提示，可拖动选点并路由到外部地图。
- 扫码固定竖屏，支持相机、相册、个人 UID、群 UID 和业务对象路由，具备明确退出与超时。
- 验收：三家地图误差可控，拒绝定位仍可手动选点，无无限加载，二维码类型不串线。

## 工程审查补充项

用户未逐项提出，但以下能力是十一领域可稳定发布的前置条件：

- **可访问性：** TalkBack 描述、焦点顺序、最小触控面积、大字体/粗体适配、高对比度和减少动态效果。
- **媒体兼容：** 记录编码、容器、色彩空间、HDR、旋转信息和动态照片配对关系；不支持的编解码器提供清晰降级。
- **性能与能耗：** 针对启动、四页切换、滚动、图片解码、视频首帧、通话温升和后台流量设预算及指标。
- **隐私与生命周期：** 缓存按账号加密隔离，退出登录清理密钥；敏感媒体可设置不自动缓存、保留期限和远程失效。
- **数据可迁移：** 用户可导出、删除和恢复个人数据；数据库迁移有版本、备份、回滚与恢复演练。
- **安全发布：** 轮换曾暴露凭据；生产 APK 固定签名；更新接口签名防重放，客户端核验包名、版本、签名和哈希。
- **内容治理：** 举报、申诉、审核、误杀恢复、恶意文件隔离和管理员操作审计形成闭环。
- **可观测性：** 崩溃、ANR、接口耗时、消息延迟、上传成功率、缓存命中、视频首帧、通话质量和数据库慢查询可追踪。
- **质量矩阵：** 历史 Fragment 生命周期、布局参数、Glide 销毁期、索引越界、组件别名等崩溃均建立回归测试。
- **契约治理：** API 使用 OpenAPI/生成模型，成功响应不得返回 HTML，错误响应统一错误码、追踪号和用户可读文案。

## 发布门禁

1. 四端单元测试、Lint、编译、APK 构建、签名与内嵌版本校验通过。
2. PHP 语法、数据库迁移、缓存/媒体策略烟雾测试和核心 API 契约测试通过。
3. 下载站版本、发布元数据、四端文件名、大小、SHA-256 和公网下载复核一致。
4. 凭据扫描不包含真实密码、私钥、生产数据或签名材料。
5. 小米、vivo、OPPO、华为和原生 Android 的媒体、缓存、通知、通话与安全区关键流程完成真机验收。
6. 资金、权限、匿名审计、文件上传、更新和管理端越权链路完成安全评审。

- 当前四端制品仍为 debug 签名验证包，只适合联调和真机验收；迁移固定 release 签名、验证覆盖安装前不得宣称为正式商用安装包。
