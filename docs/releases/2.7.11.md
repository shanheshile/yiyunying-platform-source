# 2.7.11 发布说明

发布日期：2026-08-02
Android `versionCode`：`56`

## 动态与帖子语音评论

- 动态评论和论坛帖子评论都增加独立的语音录制入口，支持麦克风授权、录制计时、最短时长校验、60 秒上限、取消和重新录制。
- 语音以独立音频附件上传，保存时长、波形和 `audio_kind=voice` 元数据；服务端再次校验媒体类型和时长，避免伪装文件进入评论。
- 动态评论与帖子评论继续复用统一媒体播放器，语音、普通音频、图片、视频和文件保持不同语义与展示方式。
- 上传或发布期间锁定重复操作，成功、取消、弹层关闭和页面销毁时都会清理临时录音文件。

## 动态评论交互

- 动态评论弹层使用输入法安全区调整，输入框随键盘抬起，不遮挡正在编辑的内容。
- 评论显示真实头像、备注或账号名、发布时间、回复对象和附件；点击头像进入对应资料卡。
- 增加评论点赞、回复、删除、Emoji 和表情包发送；打开指定评论通知时会展开评论区并定位高亮。

## 通知详情与未读同步

- 动态评论、论坛评论、回复和提及通知携带业务对象、帖子或动态摘要、评论编号、父评论和发送者信息。
- 通知详情改为中文类型化资料卡，并明确展示“点击后定位到”的目标，不再让用户面对原始 JSON 或不明字段。
- 单条已读、分类一键已读和全部已读会立即向首页发布精确未读数；首页、通知中心和数字红点使用同一计数结果。
- 点击动态评论通知定位到对应动态与评论；点击论坛评论通知定位到对应帖子、主评论或回复。

## 数据库与接口

- 新增迁移 `upgrade_20260802_moment_comment_interactions.sql`，为动态评论补充表情标识和评论点赞关系表。
- 新增动态评论点赞接口；动态评论创建接口支持文字、表情包或一条录制语音。
- 服务端统一展开通知 `data_json`，同时兼容历史嵌套载荷。
