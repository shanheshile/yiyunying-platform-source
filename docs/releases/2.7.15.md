## 本轮源码能力

### 管理端四栏与多应用控制

- 管理员主框架重构为“首页、源码示例、交流、我的”四栏，全部使用中文显示。
- 首页展示应用名称/类型、轮播区、我的应用和应用列表；支持创建、切换和删除应用，并在选中应用的上下文内管理用户、聊天、群聊、论坛、文档、资源、商城、公告/更新/维护等系统。
- 源码示例按 Android Java、iApp、Lua 等类别组织，并提供好友聊天、群聊、登录注册、论坛等模块入口。
- 交流页提供分类切换、发帖、收藏、评论、点赞、置顶、删除与举报等管理员社区入口；“我的”汇总账号、会员、额度、KEY 连接、资料、安全、官方信息、赞助与账号操作入口。
- 功能入口同时受当前应用、角色权限和服务端模块开关约束，前端隐藏不替代服务端鉴权。

### BuildConfig 登录身份链与默认凭据

- 用户端和管理端登录 UI 不再要求填写服务器地址、平台标识或应用标识；这些部署身份由开发者写入源码构建配置。
- 后端仍按角色严格核验当前地址下的账号、登录密码、平台 KEY、应用 KEY、应用 API 唯一 ID、Token 时效、撤销状态和实时登录状态。
- 登录成功后必须通过真实身份接口完成会话复核，未通过前不展示业务内容；不同角色不得复用越权身份链。
- 初始化数据库不再提供可登录的默认账号/密码，只有禁用占位身份；默认凭据审计和安全合同加入检查链。
- APK 内的 `app_key` 是公开租户唯一 ID，`app_secret` 仅保存服务端哈希且不参与客户端登录、刷新或普通请求；轮换 secret 不会使当前 APK 失效。线上既有 ID 的历史演示命名为 2.7.14 升级兼容暂时保留，若要改名必须另做别名/灰度迁移并重建。

### 用户快捷模块、短视频与群管理

- 用户首页提供私聊、群聊、红包、论坛、短视频和商城的最小快捷闭环，入口名称、错误提示和内部枚举展示均为中文。
- 短视频作为独立新功能，补齐用户发布/浏览入口、管理端治理入口、角色权限、模块开关和服务端强制校验。
- 用户端与管理端同步完善群头像回退、群资料与群成员管理；群主、管理员和普通成员的操作边界由服务端复核并保留审计。

### 三态审核与资源商店私有审核

- 管理审核统一为“通过、不通过、暂定”三种操作和中文状态，不再以含混开关代替审核决策。
- 应用商店、资源管理、论坛、动态、评论等对象补齐审核入口、权限、拒绝原因、状态回读和审计合同。
- 应用/源码等待审核文件进入私有目录，通过鉴权接口访问；只有审核、扫描和引用检查满足条件后才能公开，关闭功能不会误公开或误删已售/被引用内容。

### 相机、媒体与页面交互

- 软件内拍照和录像支持变焦；录像过程中仍可点按、拖动并锁定聚焦。
- 拍摄完成后在当前拍摄页面固定预览照片或录像；点击“✓”确认后才进入发送，取消则返回拍摄状态继续重拍。
- 媒体堆叠的当前媒体在拖动全过程跟随手势，并在边界、取消和反向切换时保持可恢复动画状态。
- 好友/聊天设置、资料页及同类页面统一处理状态栏、刘海和导航手势安全区。
- 共享弹层修复上滑后下滑手势接管问题；弹窗、按钮、分类、草稿、章节与发帖 UI 使用主题语义色，避免字体、背景和按钮对比失配。

### 论坛评论、发帖与解锁

- 评论列表只直接展示主评论；根评论下的回复默认以预览形式呈现，点击小字“更多”再加载其余回复。
- 回复项显示“谁回复谁”，支持只看相关评论，并提供按时间、热度、综合排序和稳定分页；帖子与论坛列表使用相同查看逻辑。
- 发帖入口、分类选择、存草稿、添加章节及相关弹窗统一主题 UI；免费、余额付费、定时和组合解锁继续由服务端校验，客户端不能绕过。

### 发布与生产安全门禁

- SSH 工具要求显式固定 `known_hosts` 并拒绝未知主机，不接受自动信任。
- 后端部署按备份、维护停写、迁移、私有目录迁移、报告核验、功能门禁激活、健康回读和失败回滚执行。
- Android 发布要求恰好四个角色包，逐包核验包名、版本、大小、SHA-256 和唯一签名；完整下载、强 ETag、`If-Range`/`206`、`If-None-Match`/`304` 均为激活前门禁。
- 更新策略只在四包与生产身份全部通过后原子激活，失败保留旧策略并清理候选；源码打包拒绝脏工作树和未跟踪实现。
