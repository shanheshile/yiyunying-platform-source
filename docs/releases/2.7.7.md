# 2.7.7 发布说明

发布日期：2026-08-01

版本：`2.7.7`（Android `versionCode 52`）

本页只记录当前源码、数据库迁移、自动化测试或发布产物能够复现的结果。2.7.6 已经正常的小米 Dock 本版不再调整。

## 本版修复

### 个人动态置顶显示

- 公共动态继续按发布时间与可见天数过滤，不向其他用户展示普通账号的置顶分区或置顶排序。
- 进入指定用户的动态空间或单条动态详情时，置顶动态可以越过“三天/一个月”等时间窗口，显示在“置顶动态”区域。
- 置顶只绕过时间范围，不绕过黑名单、好友关系、仅指定用户、排除用户、私密动态等权限判断。
- 新增策略回归测试，分别覆盖公共动态、个人动态空间、详情页和隐私拒绝场景。

### 论坛评论回复归属

- 评论表新增稳定的 `root_comment_id`，同时保留 `parent_id` 作为直接回复对象；“显示回复谁”和“归属哪个主评论”不再共用一个易漂移字段。
- 新评论在服务端事务中解析并保存主评论根锚点；读取旧评论时兼容历史父链并补出稳定根锚点。
- Android 按根锚点组织评论线程，保持主评论原顺序，并把所有直接回复和多级回复放回所属主评论下。
- 新增幂等数据库迁移与旧数据回填，避免新增主评论、分页或列表顺序变化后回复串到另一条主评论。
- 新增 Android 单元测试和 PHP 契约测试，覆盖 `1 / 2 / 4回复1 / 5`、多级回复、旧数据和分页缺少根评论等场景。

### 完整项目交付

- 下载中心新增完整源码快照、完整 Git 历史包、项目交接总包和项目文件校验清单入口。
- 发布元数据升级为 schema 3；部署前会同时核验四端 APK 与四类项目文件，避免网页版本、APK、源码包和 Git 历史不一致。
- 项目包只从干净提交生成，不包含构建缓存、本地凭据、签名私钥或生产数据。

## 数据库迁移

按 `backend/database/MIGRATION_ORDER.md` 顺序执行：

```text
backend/database/migrations/upgrade_20260801_forum_comment_threads.sql
```

迁移可重复执行，并为旧评论逐层回填顶级评论根锚点。

## 自动化验证

- 后端角色权限、红包、商业退款、动态置顶策略、论坛评论线程契约、PHP 语法、SQL BOM 和 PowerShell 语法检查通过。
- 下载中心 lint、构建、服务端渲染、版本与下载链接一致性测试通过。
- Android 评论线程专项单元测试通过；四端完整构建共执行 226 个任务，四个 APK 的应用身份、版本、签名、体积和 SHA-256 校验全部通过。

## 发布边界

- 当前四端为 debug 签名验证包，不冒充正式商用 release 包。
- 动态可见范围与评论旧数据迁移仍需在生产备份后执行，并进行真实账号/真实帖子联调。
- 通话、资金、地图、实时 AI、四级治理等历史目标不因本次两个专项修复而自动视为完成，继续以总纲和各版本验收记录为准。
