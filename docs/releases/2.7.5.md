# 2.7.5 发布说明与十一领域验收矩阵

发布日期：2026-08-01

版本：`2.7.5`（Android `versionCode 50`）

本页只记录可由当前源码、单元测试、构建产物或公网发布结果复核的事实。完整需求编号、实施顺序和完成定义见 [全量需求与实施总纲](../MASTER_REQUIREMENTS_AND_IMPLEMENTATION_PLAN.md)。存在页面或按钮不等于业务闭环完成，涉及通话、资金、地图、实时 AI 与四级治理的能力仍需服务端联调、安全评审和真机验收。

## 本版可核验完成

### 小米 Dock 专项适配

- Dock 厂商策略明确区分 Xiaomi、Redmi、POCO 与其他品牌；小米系增加字体度量和底部安全高度，避免标签只显示半行。
- vivo 继续使用既有正常尺寸，不套用小米补偿，防止正常设备被二次放大或增加留白。
- 标签关闭位移动画并保持稳定触控区；新增纯策略单元测试覆盖 Xiaomi、Redmi、POCO、vivo 和 OPPO。

### 更新检查与下载进度

- 设置页“立即检查”改为真实请求更新/维护接口，不再只刷新静态说明。
- 自动检查和手动检查共用同一版本比较逻辑；无更新时明确显示当前版本，失败时给出可理解错误。
- 更新下载弹层禁止误触外部关闭；通知栏显示下载进度、下载完成安装入口与失败状态。
- 安装前继续核对 SHA-256、文件大小、包名和版本，通知小图标跟随当前应用图标配置。

### 聊天时间节点

- 聊天记录按跨日或至少五分钟间隔插入不可删除的时间节点，不再为每条消息重复显示时间。
- 时间文案按当天、本周、本年和更早记录采用不同精度；点击节点可展开完整年月日、星期和时间。
- 时间节点加入消息列表布局，不改变消息本身的 ID、选择状态或发送内容。

### 继承并复核 2.7.4 能力

- 保留账号隔离的自动缓存、分类清理、容量和保留期限设置。
- 保留视频自动播放与缓存网络策略，并继续接受服务端默认值和平台上限。
- 保留图片、GIF、动态照片、视频、语音、音频、文档和普通文件的类型化预览。

## 自动化验证

- Android 四角色 Lint 全部通过；原子发布构建完成 226 项任务，包内版本、包名、大小与 SHA-256 校验通过；Dock 厂商策略 3 项和聊天时间格式 4 项定向单元测试通过。
- 后端静态验证通过：171 个 PHP 文件、214 张表、757 条 API 路由、410 条文档化接口、97 条需求核验记录；角色权限、红包金额/规则和退款策略测试通过。
- 仓库敏感信息与大文件扫描、环境加载测试、下载站 ESLint、生产构建及 2 项渲染/元数据测试通过。ESLint 仅保留 4 条 `<img>` 性能建议，无错误。
- 四端制品哈希：用户端 `D0B795E4...F88477`、管理员 `307E1148...1E8A0`、授权平台 `3AD7FE41...310B`、平台总控 `D31B9570...F2BE`；完整值保存在 `releases/2.7.5/release-manifest.json`。
- 公网更新接口、下载站版本和 APK 复下载哈希仍须在部署后复核，未部署前不记为通过。
- 小米/vivo 的最终视觉差异仍必须使用对应真机截图验收；单元测试只能证明策略分支与尺寸计算，不代替厂商系统渲染验证。
- 当前制品仍是 debug 签名验证包；在固定 release 签名和覆盖安装验证完成前，不宣称为正式商用包。

## 发布门禁

1. 四端测试、Lint、编译、APK 构建、签名、包名、包内版本、大小与 SHA-256 一致。
2. 后端 PHP 语法、数据库迁移、权限和核心业务静态检查通过。
3. 下载站、更新接口、发布清单和四端 APK 同为 `2.7.5 (50)`。
4. 公网 APK 返回有效 ZIP/APK 内容，重新下载后的 SHA-256 与发布清单一致。
5. 小米 Dock 不裁字且 vivo 布局不回归；更新下载不可误关闭，通知进度与安装入口可用。
6. 凭据扫描不包含真实密码、私钥、生产数据或签名材料。
