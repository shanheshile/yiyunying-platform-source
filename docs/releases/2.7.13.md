# 2.7.13 Debug 测试版说明

发布日期：2026-08-10
Android `versionCode`：`58`

## 聊天与媒体

- 短文本气泡按文字实际宽度贴合，保留通话卡片等结构化消息的安全最小宽度。
- 聊天轮询不再对无变化结果重复刷新和滚到底部；适配器增加消息 ID 索引、稳定更新和低内存媒体缩略图路径。
- 更多功能可重复点击保持展开；短按拍摄进入软件内相机，轻触拍照、长按录像且最长 60 秒，完成后统一走本地媒体优化。
- 长按拍摄调用系统原生相机，长按相册进入完整相册，长按名片直接发送本人名片。
- 拍摄、相册、名片和通话记录标签均支持管理员开关，并由服务端对可信上传场景复核。

## 评论、导航与界面

- 私聊、群聊、聊天室、动态、帖子、评论、收藏和板块页面支持双击顶部中央快速回到顶部。
- 动态评论弹层增加实体背景和裁剪视口，修复标题未对齐、圆角外穿透及漏出其他评论。
- 论坛回复收纳到对应根评论内部，默认预览两条，展开/收起控件缩小并保持稳定根锚点。
- 语音评论和内联音频增加可拖动进度条；完善准备、错误、重试、倍速和拖动状态保护。
- 首页消息、动态和活动快捷按钮统一浅色/深色主题对比度，并按管理员策略过滤入口。

## 资料、头像与管理员控制

- 重整本人、好友、群聊、聊天室和当前聊天设置页面的信息层级、资料卡及管理入口。
- 增加群聊、聊天室和板块头像上传；创建、更新和上传入口均执行租户、管理者及功能开关校验。
- 管理端保存功能开关时保留既有 `config_json`，避免只改启用状态却清空配置。

## 帖子章节与解锁

- 正文、章节和附件可分别设置免费、余额付费、按日期解锁或“付费/到期任一满足”解锁。
- 支持多章节草稿、独立附件、严格 UTC 时间校验、价格和最远日期上限。
- 付费及定时附件使用私有存储和短期签名地址；客户端在到期前、恢复前台及点击播放前刷新。
- 发布媒体不再暴露原始文件名；隐私规则为安全强制项，不能被管理员关闭。

## 数据与安全一致性

- 旧整帖付费内容在列表、搜索、收藏、历史、公开主页和详情出口统一执行购买权限脱敏。
- 购买仅允许审核通过内容，资产固定记录为 `balance`，并禁止破坏已有购买权益的修改、删除或上传移除。
- `client_draft_id` 与数据库唯一约束保证重复点击/网络重试不会重复创建帖子、奖励或日志。
- 私有媒体签名密钥在生产环境缺失或弱配置时失败关闭；修复 Range、贴纸绕过及公共附件转付费等问题。
