## 状态口径

仓库采用以下状态描述，避免把界面入口、代码草案或历史记录误写为生产完成：

| 状态 | 含义 |
| --- | --- |
| 源码入口可见 | 能定位到页面、路由、接口或数据结构，但未证明完整闭环 |
| 构建可核验 | 可通过本地构建、静态检查或自动化测试 |
| 需集成验收 | 需要客户端、API、数据库或第三方服务联调 |
| 需真机验收 | 需要 Android 设备、厂商系统、网络或权限环境验证 |
| 持续完善 | 已有实现，但稳定性、性能、可访问性或交互仍需改进 |
| 需求记录 | 已记录目标，尚不能声称实现 |

## 已确认事实

- 当前源码版本为 `2.7.8`，Android `versionCode` 为 `53`。
- 仓库包含用户端、管理员端、授权端、总控端四种 Android 构建形态。
- 后端采用 PHP API 与 MySQL，客户端依赖推送、WebSocket、TURN/STUN、地图、天气、语音识别等外部能力。
- 本仓库只有从 `2.7.2` 建立的真实 Git 历史；更早历史由本机归档和发布证据重建，未伪造旧提交。
- 归档校验和与来源记录见 [源码来源](history/SOURCE_PROVENANCE.md) 和 [归档校验和](history/ARCHIVE_CHECKSUMS.md)。

## 2026-07-31 追加稳定化修复

本批次在 `2.7.3 (48)` 源码基线上完成，并已通过不依赖 Android SDK 的自动化校验：

- 用户端与管理端首页 Dock 统一由 `BottomDockStyler` 管理，固定显示文字并关闭位移动画，避免入口挤压、错位和文字消失；
- 共享弹层在按钮背景已被覆盖时不再调用 Material Shape API，避免重复换肤和二次渲染闪退；
- 通知和通话前台服务使用统一通知图标解析器，支持默认、简约和深色图标配置；
- 私聊、群聊和聊天室标题区按对象类型进入资料卡与权限管理，后端与数据库迁移补充 `room_kind`，避免群聊和聊天室路由串线；
- 生活动态补充个人动态入口、置顶分区与删除流程，置顶只在进入对应用户动态空间后突出显示；
- 管理端用户监管、资料卡和通知详情继续采用结构化字段卡片，不向用户展示原始 JSON；
- 中英日语言链路只翻译固定界面文案，昵称、备注、账号、签名和消息正文继续保持原文；
- PHP 语法、下载站构建与服务端渲染、版本链、下载链接、敏感信息和大文件扫描均已通过。

Android 编译尚未在本批次重新执行：本机缺少已接受许可的 Android 36 SDK。接受 SDK 许可属于第三方条款确认，必须由用户明确同意；在此之前，本批次状态为“源码与非 Android 自动化可核验”，不等同于四端 APK 或真机验收完成。

## 发布阻断项

### P0：历史凭据必须轮换

项目沟通过程中曾暴露服务器、面板、SSH 和数据库凭据。即使当前源码未检出这些明文，也必须视为已泄露并完成轮换；禁止把真实凭据、数据库数据、签名密钥或访问令牌提交到 Git。

### P0：正式发布链路尚需证明

公开下载不得使用 debug APK。必须验证 release 构建、签名连续性、升级兼容、回滚策略、强制更新策略和防降级校验。
