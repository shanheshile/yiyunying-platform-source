# 易运盈后台 2.6.17

## 本次闭环

- 1、2、3 级从下级用户资料进入通信管理后，可选择具体私聊对象，不再只能查看混合消息总表。
- 群聊、聊天室和客服会话按目标 user 的真实参与关系进入，界面明确显示“谁进入哪个会话”。
- 管理会话顶部显示目标 user、私聊另一方、会话类型和编号，并固定按目标 user 视角排列消息。
- 管理者可在授权范围内发送系统消息、修改或删除具体消息；普通 user 不暴露真实管理身份，审计记录保留真实操作者。
- 私聊非参与者、群聊非成员、跨 admin、跨应用和跨授权平台读取均返回拒绝，不能仅凭会话编号越权。
- 用户详情补齐好友、关注、粉丝、笔记、论坛、悬赏、私聊、群聊、聊天室和客服会话入口。
- 悬赏审核支持待审核、通过、不通过及原因，并补齐内容修改、删除和退款闭环。
- 笔记支持按年、月、日和日期区间检索；论坛热度提示只依据真实浏览、评论、点赞和热度数据。

## 验收重点

- A 与 B 的私聊可由所属 1/2/3 级从 A 或 B 的用户资料精确进入。
- 无关用户 C 不能借用同一私聊编号读取消息。
- 群成员可从用户资料进入具体群聊，非成员不能借用群编号进入。
- 页面离开后异步返回不会再对未附着 Fragment 打开弹窗。
- 四种 Android flavor 均能完成资源处理和 Java 编译。
