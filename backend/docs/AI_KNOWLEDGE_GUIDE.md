# 易运盈本地 AI 与跨学科知识库

## 能力边界

易运盈智能机器人由四层共同完成，不是固定关键词问答：

1. 实时工具层：天气、定位、时间等必须读取实时数据，不能依靠模型记忆猜测。
2. 租户知识层：1 级、2 级和 admin 可维护自己的制度、教材、产品、地方文化与专业资料。
3. 本地模型层：Ollama 中的中文通用模型负责理解问题、连续对话、归纳、比较与解释。
4. 离线兜底层：模型或网络不可用时，继续使用应用固定问答库和明确的降级提示。

本地模型默认能够处理文学、语言、历史、人文、文化、地理、农学、自然科学、数学、工程技术、哲学、教育、旅行和生活常识。知识库不是为了重复录入百科全书，而是补充模型不知道、容易过时或必须服从当前租户口径的内容。

## 建议分类

当前数据库使用“标题 + 关键词 + 正文”检索，不强制增加僵硬的分类字段。维护时在关键词中加入以下学科标签即可交叉检索：

| 大类 | 推荐关键词示例 | 适合内容 |
| --- | --- | --- |
| 文学语言 | `文学,古诗词,现代文学,写作,语言学` | 作品背景、体裁、修辞、写作规范 |
| 历史人文 | `历史,考古,民俗,社会,人物` | 历史事件、人物关系、地方志、民俗 |
| 文化艺术 | `文化,艺术,音乐,美术,非遗` | 文化背景、艺术流派、非遗资料 |
| 地理旅行 | `地理,城市,地貌,旅行,景点` | 自然地理、人文地理、景区资料与本地攻略 |
| 农学 | `农学,作物,土壤,植保,畜牧,农机` | 栽培、病虫害、农机、农事标准；涉及农药时必须注明来源和适用范围 |
| 自然科学 | `物理,化学,生物,天文,地球科学` | 基础概念、原理、实验边界和科学史 |
| 数学工程 | `数学,统计,计算机,工程,技术` | 公式解释、算法、工程规范和技术文档 |
| 哲学教育 | `哲学,逻辑,伦理,教育,心理` | 流派比较、论证结构、教育资料；争议观点必须并列说明 |
| 应用业务 | `易运盈,应用规则,操作说明,售后` | 当前应用真实功能、规则、价格、流程与客服口径 |

## 四级继承规则

- 1 级 `global`：本根平台整棵树可用，只有 1 级可修改。
- 1/2 级 `platform`：仅当前平台分支可用；2 级不能改上级下发内容。
- 平台 `admin`：仅指定管理员及其应用可用。
- 平台或 admin `app`：仅指定应用的 user 可用。
- 3 级 admin 只能维护自己应用的知识，不能读取或修改其他 admin 的私有知识。
- 4 级 user 只能问答，不提供知识管理入口，也看不到模型地址、密钥和内部提示词。

## 编写规范

每条知识只表达一个主题，标题要能独立识别，正文建议控制在 300-3000 字。长文应按章节拆分，并在每条记录中保留相同的来源链接和章节关键词。

推荐结构：

```text
标题：冬小麦拔节期水肥管理
关键词：农学,小麦,拔节期,水肥,华北
来源链接：https://example.gov.cn/...
正文：
适用地区：……
适用时期：……
核心做法：……
限制与例外：……
资料发布日期：2026-03-01
```

## 可信度规则

- 科学、农学和工程资料优先使用政府、大学、科研院所、标准原文与设备官方文档。
- 文学、历史、文化和哲学应区分原始文本、学界主流解释与存在争议的观点。
- 医疗、法律、农药剂量、金融和安全操作属于高风险内容，知识正文必须写清来源、日期、适用地区和限制，回答中不得把一般资料冒充个体专业意见。
- 天气、新闻、价格、法规和政策具有时效性，不应作为永久事实写入知识库；应通过实时工具查询或明确标注资料日期。
- 不录入密码、令牌、数据库连接、身份证件和其他敏感信息。

## 安卓端维护

- 1/2 级软件：进入“智能 -> AI 综合知识库”，可按 `global/platform/admin/app` 选择范围。
- admin 软件：进入“智能 -> AI 综合知识库”，内容自动绑定当前应用。
- “固定问答库”保留给短句、客服口径和模型不可用时的快速兜底。
- user 软件的智能机器人会自动携带会话编号，支持连续追问；知识来源会随回答返回，但不会泄露内部租户字段。

## 模型选择

- 低内存服务器：`qwen2.5:1.5b`，响应快，适合基础问答与应用知识。
- 普通服务器：`qwen2.5:3b`，默认方案，综合能力与资源占用较平衡。
- 更高内存服务器：可通过 `AI_MODEL` 换成已在 Ollama 安装的更大中文指令模型，不需要修改 PHP 或重新打安卓包。

模型变更后执行：

```bash
AI_MODEL=qwen2.5:3b deploy/local-ai/verify-environment.sh
```

只有自检确认 Ollama、模型、PHP 扩展和真实问答均正常后，才应在生产环境启用。
