# 易运盈平台账号密码（仅限本机私有使用）

- 双击 `打开账号管理.cmd`：默认显示全部启用账号，可搜索、排序、显示或隐藏、复制、编辑、软删除、撤销、永久删除、导入和导出。
- 双击 `打开测试账号.cmd`：默认显示人工标记为 test 的账号，也可切换到全部可登录和已停用视图。
- 源 DPAPI 包没有生产或测试环境字段，因此所有启用账号初始为 `unknown（待确认）`。核对后请在页面改为 `test` 或 `production` 并保存。
- `active` 仅代表源账号状态为启用；本次导出没有逐账号实时登录，所以不标记成“已验证可登录”。
- `disabled/inactive` 单独进入“已停用”视图和 `JSON/已停用_不可登录.json`，不会混入可登录账号。
- 保存前自动在 `Backups` 下创建快照；写入失败会回滚。所有持久化文件只在本目录，目录 ACL 仅允许当前 Windows 用户和 SYSTEM。
- 这是明文凭据目录。不要上传、分享、同步到网盘或提交 Git；使用完请点击页面“安全关闭”。
